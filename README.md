# Tom's Missed Screen Share Counter 🎯

***Counting the Misses, One Screen at a Time!***

![This photo shows the counter in action](/Images/Screenshot.png)

## 📝 Overview

Tom's Screen Miss Counter is a playful web application that began as an inside joke in a Tech Elevator class. During one session, our instructor forgot to share their screen multiple times. This inspired the creation of a small, interactive counter that tracks the number of times “Tom” has missed sharing his screen.

What started as a humorous side project quickly became an opportunity to practice DOM manipulation, event handling, local storage, and responsive web design.

## ⚡ Features

- 🖱 **Click Counter:** Each time the button is clicked, the counter increments and displays the total misses.

- 💾 **Persistent Storage:** Uses localStorage to remember the counter across page reloads.

- 🖼 **Dynamic Image Update:** Changes Tom’s image on the first click to reflect the “missed screen” moment.

- 📱 **Responsive Design:** Fully centered and mobile-friendly layout with a fun color scheme.

- 👀 **Hidden Counter:** Counter is hidden initially and only appears once Tom misses a screen share.

## 🛠 Technologies Used

- **HTML5:** Structuring the main elements and semantic layout.

- **CSS3:** Styling the page, centering elements, responsive layout, and rounded images.

- **JavaScript (Vanilla):**

     - DOM selection and manipulation (getElementById, querySelector)

     - Event listeners (addEventListener)

     - Local storage (localStorage) for persistence

     - Conditional logic for image switching
